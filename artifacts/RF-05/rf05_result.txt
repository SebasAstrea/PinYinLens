RF-05 Diccionario bilingüe + pulsación sostenida (hold 5 s) — e2e
Fecha: 2026-11-16
Dispositivo: SM-A226BR (Android 13)

== Implementación ==
- gesture/HoldDetector: máquina de estados pura para el hold de 5000±150 ms.
  Rechaza taps rápidos (<500 ms) y scrolls (desplazamiento > slop).
- dictionary/: DictionaryEntry, CharacterGloss, DictionarySource (interfaz),
  DictionaryCard + DictionaryCardBuilder (desglose por carácter). Lógica pura.
- app/dict/SqliteDictionary: base SQLite indexada por 'simplified' (RNF-05,
  desacoplada del binario), consulta < 15 ms (RNF-01). + DictionarySeed.
- app/ui/DictionaryCardView: tarjeta flotante sobre el overlay.
- AccessibilityService: camino hold -> consulta -> tarjeta.

== Detector de hold (gate binomial, HoldDetectorAcceptanceTest) ==
n=100 holds válidos: T_hold = 1.0 (100/100). p=7.05e-4 -> H0:P<=0.93 RECHAZADA.
n=200 taps rápidos/scroll: 0 falsos positivos.
Umbral SRS: T_hold >= 0.97 (CUMPLIDO); 0% falsos positivos (CUMPLIDO).

== Consulta a diccionario (RNF-01 < 15 ms) ==
20 consultas en estado estable: media = 1.76 ms, máx = 3.52 ms, todas < 15 ms.
Primera consulta (con apertura de DB): 5.2 ms. CUMPLIDO.

== Alcance / pendientes ==
- Completitud C_dic >= 0.98 (HSK 1-6): requiere CC-CEDICT completo + glosas ES/EN
  (semilla de 20 entradas para verificación; dato real desacoplado, RNF-05).
- Integración del hold con las zonas de pinyin dibujadas: depende de render
  (RF-04/render). El camino hold->tarjeta se verificó vía broadcast de prueba;
  la detección del hold está validada por HoldDetector(+gate).

VEREDICTO RF-05: T_hold=1.0 (>=0.97), 0 falsos positivos, consulta<15ms, tarjeta
bilingüe completa. APROBADO en mecanismo. Completitud de datos pendiente de
CC-CEDICT real; enganche táctil al pinyin pendiente de render.

== e2e 2026-11-17: enganche del hold al pinyin dibujado (RF-01/RF-05) ==
- La capa de dibujo es FLAG_NOT_TOUCHABLE (pass-through). La interacción son
  ventanas minúsculas por etiqueta (PinyinTouchTargets), no una ventana
  full-screen. Navegación verificada en Settings: tap fuera de etiquetas abre
  Conexiones; scroll en el borde derecho desplaza y RF-06 regenera (0.28 s).
- Hold de 5.2 s sobre la etiqueta 设置 (target 404,533-676,643):
  hold fired word='设置'; lookup 3.76-6.06 ms, found=true; card shown.
  Tarjeta: 设置 (設置) / shè zhì / 设 置 / ES: para poner arriba; para instalar /
  EN: to set up; to install. Evidencia: rf05_hold_card_live.png, rf05_hold_live.log.
- Tap rápido sobre la misma etiqueta: 0 hold, 0 tarjeta (sin falsos positivos).
  Evidencia: rf05_hold_no_false_positive.png.
- Bug corregido durante la verificación: los re-escaneos retiraban/recreaban las
  ventanas táctiles durante el gesto y cancelaban el hold. Ahora se ignoran los
  eventos del propio paquete y las actualizaciones se difieren hasta ACTION_UP.
- Limitación de datos (preexistente): la etiqueta debe existir en el diccionario
  cargado. 连接/屏幕 no están en el TSV HSK incluido, así que no muestran tarjeta.
