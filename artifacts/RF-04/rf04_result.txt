RF-04 Segmentación léxica y conversión contextual a pinyin
Fecha: 2026-11-16

== Implementación (módulo pinyin, JVM puro) ==
- ToneMarks: tono numérico (ni3) -> diacrítico (nǐ), reglas estándar de colocación.
- Lexicon: Trie + carga desde CC-CEDICT (RNF-05: datos desacoplados del binario).
- PinyinConverter: segmentación por máxima coincidencia hacia adelante +
  desambiguación polifónica por contexto (la palabra manda sobre el carácter).

== Desambiguación polifónica (caracteres del SRS: 行 长 着 了 地) ==
Verificada por PinyinConverterTest:
  银行 -> yín háng   / 不行 -> bù xíng
  长大 -> zhǎng dà   / 长度 -> cháng dù
  了解 -> liǎo jiě   / 了   -> le
  着急 -> zháo jí     / 看着 -> kàn zhe
  慢慢地 -> màn màn de / 地方 -> dì fāng
